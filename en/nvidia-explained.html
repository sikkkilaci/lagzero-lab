NVIDIA Control Panel – 3D settings

A clear overview of the recommended global settings.

How to read the bars: the further right, the stronger the tendency in that category. The values are not measured FPS or millisecond values. The real effect depends on game, API, GPU and monitor.
1

Antialiasing – FXAA

Off

What does it do? Post-processing anti-aliasing. Smooths edges after rendering but can make the image look slightly soft.

Effect: Off saves a little GPU work and leaves the actual anti-aliasing to the game.

Relative tendency – not an FPS benchmark
Performance
90
Quality
70
Latency
90

Antialiasing – Mode

Application-controlled

What does it do? Decides whether the NVIDIA driver forces anti-aliasing or the game decides itself.

Effect: The game keeps control and avoids conflicts with its own AA implementation.

Performance
95

Antialiasing – Setting

Application-controlled

What does it do? Sets the strength of classic MSAA if the selected AA mode uses it.

Effect: No driver override; the game sets the level and therefore the cost.

Antialiasing – Gamma correction

What does it do? Improves how smoothed edges look by using gamma-corrected calculation.

Effect: Can improve edge quality; the performance impact is usually small.

Antialiasing – Transparency

Anisotropic filtering

Application-controlled

What does it do? Improves the sharpness of textures seen at an angle, such as floors and roads.

Effect: The game sets the AF level. Higher levels improve texture quality; the performance cost on modern GPUs is often small.

Ambient occlusion

Effect: Off saves GPU performance but removes this extra shading.

Power management mode

Prefer maximum performance

What does it do? Controls how aggressively the GPU lowers clock speeds and power states.

Effect: The GPU keeps higher clocks when needed. This can reduce latency and clock changes but increases power draw and heat.

Relative tendency – not an FPS benchmark

Preferred refresh rate

Highest available

What does it do? Sets which available refresh rate is preferred.

Effect: The highest Hz allows shorter scan-out time and a smoother image, as long as monitor and game use it.

Low Latency Mode

On

What does it do? Limits the number of frames the driver queues before rendering.

Effect: Can reduce input latency, especially in GPU-bound DX9/DX11 games. In supported games NVIDIA Reflex is the preferred solution.

Relative tendency – not an FPS benchmark
Performance
95
Quality
100
Latency
90
With DX12/Vulkan the application has more control over the render queue.

Shader Cache Size

100 GB

What does it do? Sets the storage limit for compiled shader cache data.

Effect: A large cache can prevent unnecessary recompiling. It does not automatically raise FPS and needs free disk space.

Effect: Can gain performance with a possible small loss in filtering quality.

Texture filtering – Negative LOD bias

Allow

What does it do? Allows applications to use a negative level-of-detail bias with anisotropic filtering.

Effect: Can make textures look sharper but may also cause shimmering.

Texture filtering – Quality

High performance

What does it do? Bundles several driver optimisations according to the selected quality level.

Effect: High performance prioritises maximum frame rate over maximum filtering quality. Textures may look slightly less clean.
