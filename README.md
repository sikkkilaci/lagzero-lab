## Privacy & security

- Every page is a single self-contained file: no trackers, no analytics, no cookies, no external scripts or fonts.
- A strict Content Security Policy blocks all external scripts and only allows network requests to AWS ping endpoints (for the ping tests).
- Controller test results and highscores stay in your own browser (localStorage) and are never uploaded.
- Ping values are approximations measured via AWS endpoints. Not affiliated with Activision, NVIDIA or Discord.
