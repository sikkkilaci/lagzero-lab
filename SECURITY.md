# Security Policy

If you find a security problem on the LAG|ZERØ Lab site, please **do not open a public issue**.
Report it privately via GitHub's "Report a vulnerability" button (Security tab) or via a
direct message on our Discord: https://discord.gg/TjRhpfgu2c

Only the official site https://sikkkilaci.github.io/lagzero-lab/ is maintained by LAG|ZERØ.
Copies hosted anywhere else are not official and may have been modified.
